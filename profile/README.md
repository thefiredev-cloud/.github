# Portfolio

One table for every product Tanner Osterkamp builds. It is the cross-business source for names, status and links. Each product's own README and website must agree with it. If they differ, fix the product's README first, then update this table. Status is dated and names where it was read. Last checked 2026-11-10.

This is a personal GitHub account, not an organization. The Repository column is filled only for public repositories; none of these products has one. Public tools are listed in the [profile README](https://github.com/thefiredev-cloud/thefiredev-cloud).
