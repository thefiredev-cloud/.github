## Start with the free skills

[meshvault-skills-starter](https://github.com/thefiredev-cloud/meshvault-skills-starter) is MIT. Six plain Markdown files. Copy them onto a machine you already have. Run a read-only job first.

| Skill | Job | Stop rule |
|-------|-----|-----------|
| [Invoice Chaser](https://github.com/thefiredev-cloud/meshvault-skills-starter/tree/main/skills/invoice-chaser) | Draft one reminder per overdue invoice. | Nothing sends until you approve. |
| [Inbox Triage](https://github.com/thefiredev-cloud/meshvault-skills-starter/tree/main/skills/inbox-triage) | Sort unread mail into three buckets. | No reply, delete, or unsubscribe. |
| [Client Follow-Up](https://github.com/thefiredev-cloud/meshvault-skills-starter/tree/main/skills/client-followup) | Find quiet contacts. Draft a short note. | Nothing sends until you approve. |
| [Meeting Brief](https://github.com/thefiredev-cloud/meshvault-skills-starter/tree/main/skills/meeting-brief) | Five-minute prep pack. | Read only. |
| [Daily Standup](https://github.com/thefiredev-cloud/meshvault-skills-starter/tree/main/skills/daily-standup) | Start-of-day brief from notes you already keep. | Read only. Changes nothing. |
| [Agents on Device](https://github.com/thefiredev-cloud/meshvault-skills-starter/tree/main/skills/agents-on-device) | Put a gated agent on hardware you already have. | Stop before a send, payment, post, or delete. |

The $49 pack is the paid set. These six files are the free set.
